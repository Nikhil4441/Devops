6. Python for DevOps Automation

OS & System

import os
print(os.listdir("/"))


Subprocess (Run shell commands)

import subprocess
subprocess.run(["ls", "-l"])


Working with JSON/YAML (common in configs, Kubernetes, Terraform, Ansible)

import json
data = '{"name": "app", "version": 1}'
parsed = json.loads(data)
print(parsed["name"])

import yaml  # pip install pyyaml
with open("config.yaml") as f:
    config = yaml.safe_load(f)
    print(config)


APIs & HTTP Calls (Monitoring, Cloud APIs)

import requests
response = requests.get("https://api.github.com")
print(response.json())


Regex for Log Parsing

import re
log = "Error: failed at line 23"
match = re.search(r"line (\d+)", log)
print(match.group(1))   # 23

8. Scripting Examples

Automate Log Cleanup

import os, time

log_dir = "/var/log/myapp"
now = time.time()

for f in os.listdir(log_dir):
    path = os.path.join(log_dir, f)
    if os.stat(path).st_mtime < now - 7*86400:  # older than 7 days
        os.remove(path)
        print(f"Deleted {f}")


Check Service Health

import requests

url = "http://myapp/health"
r = requests.get(url)
if r.status_code == 200:
    print("Service is healthy")
else:
    print("Service is down")

9. Best Practices for DevOps Python

Write small, reusable scripts (not big apps)

Always handle exceptions

try:
    1 / 0
except ZeroDivisionError as e:
    print("Error:", e)


Use virtual environments (python -m venv venv)

Document with comments
